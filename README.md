# BBQ Town Dickson Buffet Operations

Tablet-friendly bilingual buffet operations system for FOH, Section 1, Section 2 and Manager.

## Current features

- 56 confirmed buffet items (Section 1: 40, Section 2: 16)
- GOOD / LOW / EMPTY floor workflow
- Kitchen workflow ending at Ready to Refill
- FOH refill confirmation and new 2/4 hour batch timer
- Bulk start for all dishes with confirmation and audit log
- English / Chinese interface
- Shared cloud database synchronization across devices
- Manager history and CSV export

## Production

The production site is hosted privately. Operational records and credentials are not stored in this repository.

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
npm run build
```
